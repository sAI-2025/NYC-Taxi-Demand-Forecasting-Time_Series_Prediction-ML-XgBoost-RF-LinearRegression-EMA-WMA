# NYC-Taxi-Demand-Forecasting-Time_Series_Prediction-ML-XgBoost-RF-LinearRegression-EMA-WMA
A real-time time series project to predict NYC Yellow Taxi demand 10 minutes ahead using ML models like Linear Regression, Random Forest, XGBoost, EMA, and WMA. Helps optimize fleet usage, improve dispatch efficiency, and support smarter decisions in urban mobility.
